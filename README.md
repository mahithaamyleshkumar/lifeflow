# 🌊 LIFEFlow

### Plan your life. Track your progress. Become your best self.

**LIFEFlow** is a modern personal productivity and routine intelligence platform designed to help users plan their days, track activities, build consistent habits, understand how they spend their time, and measure their personal improvement over time.

It goes beyond a traditional To-Do application by combining **task management, time planning, habit tracking, analytics, streaks, reflections, productivity scoring, and intelligent insights** into one beautiful experience.

---

## ✨ Why LIFEFlow?

Most productivity applications answer:

> **"What do I need to do?"**

LIFEFlow goes further and asks:

> **"What did I actually do?"**
> **"How consistently am I doing it?"**
> **"Where am I spending my time?"**
> **"Am I improving?"**
> **"What patterns exist in my routine?"**

LIFEFlow transforms everyday activity logs into meaningful personal insights.

### Core Flow

```text
PLAN
  ↓
DO
  ↓
TRACK
  ↓
REFLECT
  ↓
UNDERSTAND
  ↓
IMPROVE
```

# 🧠 "Am I Improving?"

One of LIFEFlow's signature features.

### Comparisons

```text
Today vs Yesterday

This Month vs Last Month

This Year vs Previous Year
```

Metrics include:

* Completion rate
* Focus time
* Productivity score
* Habit consistency
* Completed activities
* Missed activities
* Overdue activities
* Routine adherence

Example:

> Your completion rate increased from **68% → 81%**.

> You completed **4.2 more hours** of focused work this week.

> You maintained your morning routine **6/7 days**.

If insufficient historical data exists, LIFEFlow does not fabricate comparisons.

Instead, it explains that more activity data is required.

# ⚙️ Installation

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/lifeflow.git

cd lifeflow
```

## 2. Install dependencies

### Frontend

```bash
cd frontend
npm install
```

### Backend

```bash
cd ../backend
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend directory.

Example:

```env
PORT=5000

DATABASE_URL=your_postgresql_connection_string

JWT_SECRET=your_secure_secret

FRONTEND_URL=http://localhost:5173
```

Never commit `.env` files.

Add them to `.gitignore`:

```gitignore
.env
.env.local
.env.*.local
node_modules/
dist/
```

---

# 🗃️ Database Setup

Create a PostgreSQL database.

Then configure:

```env
DATABASE_URL=your_database_url
```

Run the project's database migrations or schema setup.

Example:

```bash
npm run migrate
```

If the project uses a different migration system, follow the migration scripts included in the repository.

---

# ▶️ Running the Application

Start the backend:

```bash
cd backend
npm run dev
```

Start the frontend in another terminal:

```bash
cd frontend
npm run dev
```

The application will normally be available at:

```text
http://localhost:5173
```

# 🧭 Product Philosophy

LIFEFlow is built around five principles:

### 1. Real Data

Your progress should represent what you actually do.

### 2. Consistency Over Perfection

Missing one day doesn't erase your journey.

### 3. Reflection Creates Improvement

Understanding your behavior helps you change it.

### 4. Progress Should Be Visible

Your effort should turn into meaningful visual feedback.

### 5. Productivity Should Feel Human

The goal isn't to complete everything.

The goal is to build a sustainable life that works for you.
